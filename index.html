Algorithm Workshop

A Tkinter desktop app for running and exploring nine algorithms, from bubble and merge sort to RSA encryption, Fisher-Yates shuffling and memoised palindrome counting. It's built around the Strategy, Factory and Facade patterns, so adding a new algorithm means writing one class. It also has functional and performance tests.

Expense Tracker

A command-line tool I built for myself to log spending and see where my money goes by category. Data persists to JSON and survives a missing or corrupted file. A custom exception keeps bad amounts separate from bad input, and 11 unit tests cover the core logic. It uses only the standard library.
